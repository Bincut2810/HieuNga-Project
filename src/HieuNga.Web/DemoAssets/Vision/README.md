# Vision — demo motorcycle package

This is a **non-branded demo package** for the Xe Máy Hiếu Nga CMS importer.

## Important

- Placeholder JPEGs are **1×1 px** stubs (not Honda product photos).
- Do **not** add copyrighted manufacturer images unless you own the rights.
- Replace files in place (keep names) then use **Reimport** in Admin.

## Expected files

```
Vision/
  metadata.json
  thumbnail.jpg
  gallery/01.jpg … 04.jpg
  angles/front.jpg … front-right.jpg   (≥ 2 angles for public viewer)
  colors/black.jpg, white.jpg, red.jpg
  features/feature-01.jpg, feature-02.jpg
  technology/tech-01.jpg, tech-02.jpg
```

Legacy `360/` folders with named angle files are still accepted.

## Import

Admin → Inventory → **Import Demo Data** → Vision → **Import**.
